# KROZO — ليش الشاشة ما تحس بلمستك وأنت لابس قفاز؟

## الملفات
| الملف | الوصف |
|---|---|
| `KROZO_Touchscreen_Gloves_Reel.mp4` | الفيديو النهائي مع موسيقى هادئة |
| `KROZO_Touchscreen_Gloves_Reel_NoMusic.mp4` | نفس الفيديو بدون موسيقى — لإضافة موسيقى من مكتبة إنستغرام |

## المواصفات
- 1080×1920 (9:16) — 30 إطار/ث — H.264 + AAC 256k / 48kHz
- المدة ~108 ث (تسجيلك 118 ث؛ انقصّت الفراغات)
- الصوت: ‎-14 LUFS، قمة ‎-1.5 dB

## الصوت
- تنقية + توضيح صوتك (نفس معالجة المقاطع السابقة).
- 45 فراغ انقص لـ 0.18 ث، و11 وقفة مقصودة: بعد "قفاز…"، بعد "تستجيب فورًا!"، بعد "قطعة قماش؟"،
  بعد "نفس الشاشة؟" (نبض)، بعد "خلّني أشرح لك…"، بعد "الجزء المثير…"، بعد "…الشبكة الكهربائية؟" (نبض)،
  بعد "بالضبط!"، بين "حاجز… عازل"، بعد "سميك…"، وقبل الختام.
- موسيقى هادئة أصلية (بدون حقوق لطرف ثالث) أوطى من صوتك بحوالي 24 dB، ومقصوص منها ترددات وضوح الكلام،
  وتوطى تلقائيًا وقت الكلام.
- 57 مؤثر صوتي: لمسة فاشلة بالقفاز، ضغطة قوية، سحب القفاز، نغمة الاستجابة، نبض الأسئلة، تفكيك الشاشة،
  مسح الأقطاب، شرارات الأملاح، نغمة اكتشاف اللمس، ارتطام القفاز، صوت "ما فيه استجابة"، ونجاح القفاز الموصل.

## المشاهد (لقطة 3D واحدة متصلة بالكاميرا + نصوص على الكلام)
| الكلام | المشهد |
|---|---|
| أتحداك تلمس الشاشة وأنت لابس قفاز… حتى لو ضغطت بكل قوتك | إصبع بقفاز يضغط على أيقونة → "لا استجابة ✕"، ثم ضغطة قوية → "ولا شي ✕" |
| أول ما تشيل القفاز… لمسة خفيفة… تستجيب فورًا | القفاز ينسحب، لمسة خفيفة، الأيقونة تضيء + موجة → "استجابة فورية ✓" |
| كيف يعرف إن اللي لمسه إصبعك مو قطعة قماش؟ | بطاقتين: قطعة قماش / إصبعك + "كيف يفرّق؟" |
| السر له علاقة بالكهرباء في جسمك | الإصبع يتوهّج + "السر: كهرباء جسمك" |
| تقنية اسمها شاشة اللمس السعوية | بطاقة "شاشة اللمس السَّعَوية — Capacitive Touchscreen" |
| تحت الشاشة شبكة مسارات كهربائية… تراقب التغيرات باستمرار | تفكيك الجوال لطبقات: الزجاج / شبكة مسارات شفافة / الشاشة + خط مسح مستمر |
| كيف لمسة إصبعك تغيّر الشبكة؟ | لقطة منخفضة فوق الشبكة والمجال الكهربائي |
| جسمك فيه ماء وأملاح… يوصل الكهرباء | أيونات تتحرك داخل الإصبع + "ماء · أملاح · Na⁺ Cl⁻" |
| لما تلمس… تتغيّر السعة… تكتشف… تحدد المكان بالضبط | خطوط المجال تنسحب نحو الإصبع، عداد "تغيّر السعة" يتجاوز الحد، الخلية تضيء، علامة تصويب |
| القفاز العادي… حاجز عازل… تغيّر غير كافٍ | حاجز عازل بين القفاز والزجاج، العداد ما يوصل الحد → "ما فيه استجابة ✕" |
| المشكلة مو إنه سميك… إنه يعزل | "سميك؟" تنشطب → "عازل كهربائيًا" |
| قفازات خاصة بأطراف موصلة | طرف القفاز يضيء، العداد يتجاوز الحد → "يشتغل ✓" |
| تابعني… | بطاقة "تابع KROZO" + خاتمة |

## التحقق العلمي
| المعلومة في السكربت | الحالة |
|---|---|
| أغلب الجوالات الحديثة تستخدم شاشات لمس سَعَوية | ✅ |
| تحت الزجاج شبكة دقيقة من المسارات (أقطاب شفافة) والشاشة تراقبها باستمرار | ✅ |
| الجسم يحتوي ماء وأملاح فيوصل الكهرباء | ✅ |
| اللمس يغيّر السعة الكهربائية عند نقطة اللمس، والشاشة تحدد المكان | ✅ |
| الضغط القوي ما يفيد | ✅ الشاشة السعوية تقيس تغيّر السعة، مو الضغط |
| القفاز العادي عازل يمنع التغيّر الكافي | ✅ |
| "المشكلة مو إن القفاز سميك… المشكلة إنه عازل" | ⚠️ تبسيط مقبول: العزل هو السبب الأساسي، لكن **السُمك كمان له دور** (كل ما زادت المسافة بين الإصبع والزجاج قلّ التغيّر). عشان كذا بعض القفازات الرقيقة جدًا أحيانًا تشتغل بشكل ضعيف. ما غيّرت كلامك. |
| قفازات خاصة بأطراف موصلة للكهرباء | ✅ |

## ملاحظات
- الجوال والإصبع والقفاز في الـ3D **توضيحيين**، مو جهاز معيّن.
- عدد خطوط الشبكة في الرسم أقل من الحقيقي بكثير (للوضوح).
- كل الرسوم مصنوعة برمجيًا — لا لقطات خارجية، لا حقوق لطرف ثالث.

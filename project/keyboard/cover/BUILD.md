# Keyboard cover

Art is a three.js scene (`art.js`): phone after typing "سلا", the hidden touch-zone
map lifted off the glass with the م zone swollen, holographic thumb landing between
ن and م. Title uses the fixed cover layout (`project/tools/cover/`).

```
cd project/tools/cover
node shoot.mjs ../../keyboard/cover/index.html art.png
node cover_title.mjs art.png ../../../output/keyboard/KROZO_Keyboard_Cover.png "كيف إبهامك أكبر من الزر" "ومع ذلك تضغط" "[الزر الصح]؟"
```

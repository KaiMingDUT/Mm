## إيش تغيّر عن النسخة الأولى؟
- **بدل لقطة 3D واحدة في نفس المكان → 34 لقطة مختلفة**: قطع كل 2–4 ثواني، كل لقطة بزاوية وحركة كاميرا مختلفة
  (دفع للأمام، ماكرو قريب جدًا، لقطة من تحت، دوران كامل، شاشة مقسومة، غطسة داخل الشاشة، مونتاج سريع في الختام).
- **مشاهد واقعية**: يد بشرية حقيقية الشكل، قفاز صوف أحمر بنسيج محبوك، جوال بإطار معدني وزجاج وكاميرات، إضاءة HDR حقيقية،
  عمق ميدان (خلفية ضبابية bokeh)، حبيبات فيلم وتدرج ألوان سينمائي.
- **6 أماكن مختلفة**: شارع ليلي مع ثلج وأضواء، طاولة خشب دافية، استوديو منتجات، داخل طبقات الشاشة، داخل الإصبع (ماء وأملاح)، ألياف القفاز.
- **ألوان أكثر**: الهوية (الأزرق والسماوي) أساسية، مع أحمر للفشل ✕، أخضر للنجاح ✓، برتقالي للقفاز، أصفر للمفاجآت، وألوان الشاشة والتطبيقات.
- **نصوص حركية كبيرة** بدل البطاقات، تطلع مع الكلمة بالضبط.
- **صوت**: 131 مؤثر (ووش مع كل قطع، صوت نقر القماش، رياح الثلج، شرارات كهرباء، فقاعات، صعود قبل الكشوفات، نبض في وقفات الأسئلة)
  + موسيقى إلكترونية نبضية خفيفة (112 BPM) فيها دروبات على اللحظات المهمة، **ونفس مستوى الصوت اللي وافقت عليه**: أوطى من صوتك بحوالي 24 dB
  ومقصوص منها ترددات الكلام وتوطى تلقائيًا وقت الكلام.

## المواصفات
- 1080×1920 (9:16) — 30 إطار/ث — H.264 + AAC 256k / 48kHz — المدة ~108 ث
- الصوت: ‎-14 LUFS، قمة ‎-1.5 dB

## اللقطات
| الكلام | اللقطة |
|---|---|
| أتحداك تلمس شاشة جوالك وأنت لابس قفاز | ليل وثلج: قفاز صوف يقرب من الجوال (دفع للأمام) ← ماكرو جانبي للقفاز ينقر الزجاج ولا شي يصير |
| وتخليها تستجيب للمسة إصبعك | لقطة من فوق: القفاز ينقر أيقونة 3 مرات + ✕ حمراء مع كل نقرة |
| حتى لو ضغطت بكل قوتك | لقطة منخفضة دراماتيكية + اهتزاز كاميرا مع الضغطة |
| أول ما تشيل القفاز | القفاز ينسحب ويطلع الإصبع |
| مجرد لمسة خفيفة | ماكرو بطيء (الثلج يبطّئ) للإصبع يقرب من الأيقونة |
| تستجيب فورًا | لمسة ← موجة + التطبيق ينفتح + ومضة ← "استجابة فورية ✓" |
| كيف الجوال يعرف… مو قطعة قماش؟ | استوديو: الجوال يدور ← قطعة قماش تطيح على الشاشة |
| وإيش اللي يميّز يدك عن القفاز… نفس الشاشة؟ | **شاشة مقسومة**: قفاز يسار / إصبع يمين ← يلمسون مع بعض: ✕ و ✓ ← "ليش؟" |
| السر… الكهرباء في جسمك | اليد تصير شبه شفافة وتسري فيها خطوط كهرباء متوهجة |
| خلّني أشرح لك | الكاميرا تغطس داخل الشاشة |
| ما تستجيب لأي شيء | قلم (طرف ممحاة) ينقر + زهر بلاستيك ينطّ على الشاشة — ولا استجابة |
| شاشة اللمس السعوية | لقطة منتج للجوال يدور مع إضاءة |
| تحت الشاشة شبكة… تراقب باستمرار | الزجاج يرتفع ويكشف شبكة الأقطاب (نمط المعيّنات الحقيقي) فوق بكسلات RGB + نبضات مسح + قراءة إشارة |
| هنا يجي الجزء المثير | الكاميرا تلف لفة كاملة حول الجوال |
| كيف لمسة إصبعك تغيّر الشبكة؟ | منظور من **داخل الجوال**: الإصبع نازل فوق الزجاج وخطوط المجال تنجذب له |
| جسمك فيه ماء وأملاح… يوصل الكهرباء | داخل الإصبع: جزيئات ماء H₂O + أيونات Na⁺ و Cl⁻ تتحرك |
| لما تلمس… تتغيّر السعة… تحدد المكان بالضبط | ماكرو لمسة على طاولة خشب ← مقطع عرضي: خطوط المجال تنسحب للإصبع + بقعة حرارية ← منظر علوي وتصويب على الإحداثيات |
| لكن لما تلبس قفاز عادي… حاجز عازل | القفاز يرجع ← مقطع: ألياف الصوف بين الإصبع والزجاج + عداد "التغيّر الكهربائي: ضعيف ✕" |
| مو إنه سميك… إنه يعزل | لقطة منتج للقفاز + "سميك؟" تنشطب ← "يعزل كهربائيًا" |
| قفازات خاصة… أطراف موصلة | قفاز بطرف فضي ← ماكرو: خيوط فضية تتوهج والمجال يعدّي |
| تستخدم جوالك بدون ما تشيلها | ليل وثلج: القفاز الموصل يفتح التطبيق ✓ |
| أول مرة تعرف المعلومة؟ تابعني… | الإصبع يضغط "Follow" على صفحة KROZO ← مونتاج سريع لأقوى اللقطات ← الشعار |

|---|---|
| أغلب الجوالات الحديثة سَعَوية، وتحت الزجاج شبكة أقطاب تُراقَب باستمرار | ✅ |
| الجسم فيه ماء وأملاح فيوصل الكهرباء، واللمس يغيّر السعة عند نقطة اللمس | ✅ |

| "المشكلة مو إن القفاز سميك… إنه عازل" | ⚠️ تبسيط مقبول: العزل هو الأساس، لكن **السُمك كمان له دور**. ما غيّرت كلامك |
| قفازات بأطراف موصلة (خيوط فضة/نحاس) | ✅ |

## ملاحظات صريحة
- المشاهد **3D مولّدة** بشكل واقعي (مو تصوير حقيقي)، والجوال تصميم عام بدون شعار أي شركة، والأيقونات عامة.
- نموذج اليد من مكتبة WebXR Input Profiles (رخصة MIT)، وإضاءات HDR من Poly Haven (CC0). الموسيقى والمؤثرات مولّدة برمجيًا — بدون حقوق لطرف ثالث.
- شبكة الأقطاب في الرسم أكبر من الحقيقة بكثير عشان تنشاف.
- لو تبغى لقطات **حقيقية 100%**: صوّر 3–4 لقطات قصيرة بجوالك (يدك بالقفاز تنقر الشاشة، تشيل القفاز، تلمس) وأرسلها، وأركّبها مكان لقطات الليل.

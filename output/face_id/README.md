## الصوت
- استخدمت **الصوت الصافي كامل** بدون ما أقص أي كلمة (النسخة اللي قبل كان فيها قصّ غلط مني — انشال منها "ويجمع… لوجهك" والجملة الأخيرة. انحل).
- الشي الوحيد اللي انقص: أطراف من الوقفات الصامتة (مجموعها 0.6 ث) — وكل جزء انقص تم فحصه إنه صمت فعلي (أوطى من ‎-46 dB).
- وقفات درامية بعد: "ما يفتح؟" و"نفس الوجه…" و**"وش الفرق؟"** (نبض قلب) و"ما يقدر يشوفها…" و"خريطة ثلاثية الأبعاد لوجهك." وقبل "وعشان كذا…".

## إيش يخلي المتابع يكمل للآخر؟
- **افتتاحية خاطفة (Cold Open)**: أول ثانية نشوف لمحة من "الجواب" — وجه خريطة العمق المضيء — وبعدين قطع سريع للسؤال. المتابع يبغى يعرف إيش هذا.
- **عنوان Hook كبير** أول ثواني: "صورتك ✕ وجهك ✓ ليه؟!"
- **قطع كل 2–4 ثواني** + **ضربات كاميرا** (Zoom-blur + اهتزاز خفيف) على الكلمات المهمة: ما يفتح، يفتح، نفس الوجه، آلاف، الأبعاد، مسطّحة، والنهاية.
- **عدّاد 30,000** يعدّ قدام عينه، وشاشات مقسومة للمقارنة (صورة | وجه، عينك | كاميرا IR).
- **نهاية بمكافأة**: المقارنة الأخيرة بلون العمق، ثم ✕ كبيرة على الصورة و✓ على الوجه مع ضربة صوت — وشعار قصير (ثانيتين) عشان الإعادة التلقائية تبدأ بسرعة.

## المشاهد
| الكلام | المشهد |
|---|---|
| (أول ثانية) | لمحة خاطفة من وجه خريطة العمق ← قطع |
| ليه لو حطيت صورتك قدام الآيفون… | من ورا الجوال: يد ترفع صورة مطبوعة لنفس الوجه قدام الآيفون |
| ما يفتح؟ | شاشة القفل: Face ID يمسح… ثم **✕ Face Not Recognized** والقفل يهتز بالأحمر |
| بس لو حطيت وجهك… يفتح؟! | الوجه الحقيقي: مسح ثم **✓ Unlocked** والشاشة الرئيسية تنفتح |
| مع إن الاثنين نفس الوجه… | شاشة مقسومة: صورة \| وجه حقيقي + "نفس الوجه =" |
| طيب وش الفرق؟ | دفع بطيء + نبض قلب + "؟" |
| Face ID ما يكتفي إنه يشوف ملامح وجهك | الوجه + "ملامح وجهك" تنشطب ← "مو كفاية" |
| أول ما تشوف للشاشة | ماكرو على كاميرا TrueDepth: Dot Projector و IR Camera |
| يرسل على وجهك آلاف النقاط بالأشعة تحت الحمراء | أشعة من الجوال للوجه، **30,000 نقطة** تنتشر على الوجه + عدّاد |
| الإنسان ما يقدر يشوفها… | شاشة مقسومة: **عينك** (ما فيه شي) \| **كاميرا IR** (النقاط واضحة) |
| يعرف شكل وجهك بالتفصيل… | دوران حول سحابة النقاط |
| ويجمع… ويبني عنده خريطة ثلاثية الأبعاد | النقاط تترابط وتصير شبكة ← **خريطة عمق** ملوّنة (أبيض = أقرب، أزرق غامق = أبعد) |
| الفرق بين الصورة ووجهك الحقيقي… الصورة مسطّحة | الكاميرا تلف حول الصورة لين تصير **خط رفيع** — "مسطّحة" |
| ما توريه أي جزء أقرب وأي جزء أبعد | مقارنة جانبية بلون العمق: الوجه فيه تدرّج (أقرب ↔ أبعد)، الصورة **لون واحد** لأن كل نقاطها نفس البُعد |
| وعشان كذا ما يقدر يتعامل معها | الصورة قدام الجوال مرة ثانية ← مسح ← ✕ Face Not Recognized |
| كوجه حقيقي. | شاشة مقسومة: ✕ على الصورة و ✓ على الوجه (خريطة العمق) ← شعار KROZO |

## التحقق العلمي
| المعلومة | الحالة |
|---|---|
| Face ID يرسل آلاف النقاط بالأشعة تحت الحمراء | ✅ — أبل تقول **أكثر من 30,000 نقطة** (Dot Projector). "آلاف" صحيحة |
| الإنسان ما يشوف هالنقاط | ✅ أشعة تحت حمراء، غير مرئية للعين |
| يبني خريطة ثلاثية الأبعاد ويعرف بُعد كل جزء | ✅ (خريطة عمق من كاميرا IR + النقاط) |
| الصورة المسطّحة ما تخدعه لأنها بدون عمق | ✅ |
| "أول ما تشوف للشاشة" | ✅ Face ID يتحقق إنك تطالع الشاشة (Attention Aware) |
| ملاحظة | ⚠️ فيه كمان **Flood Illuminator** (ضوء IR يخلي Face ID يشتغل بالظلام)، وأبل تستخدم شبكات عصبية تقارن الخريطة بالمحفوظة داخل الـ Secure Enclave. ما ذكرتها لأنها مو في كلامك |

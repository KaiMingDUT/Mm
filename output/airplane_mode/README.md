## إيش الجديد مقارنة بالفيديو المرجعي؟
- **نفس الفكرة (مشاهد 3D + شرائح HUD + ترجمة كلمة بكلمة) بس بهويتك**: ليل كحلي `#080B12`، أزرق كهربائي `#168BFF`، سماوي `#59C7FF`، وخط IBM Plex Sans Arabic.
- **طائرة بهوية KROZO**: لون أبيض مع بطن أزرق وخط سماوي واسم KROZO على جسم الطائرة (نص فقط، بدون شعار مخترع)، أضواء ملاحة حقيقية تومض، نوافذ مضيئة، فوق الغيوم بالليل تحت ضوء القمر.
- **أماكن أكثر**: خارج الطائرة، المقصورة (180 مقعد وركاب وإضاءة زرقاء)، قمرة القيادة (شاشات طيران حية)، الأرض (مدينة + أبراج اتصال)، حظيرة صيانة، وعالم "هولوغرام" للتشبيه.
- **التشبيه بالصوت متجسّد**: مجسمات هولوغرام — أنت، شخص يكلمك بهدوء، وشخص ثاني جنب أذنك — مع لوحة موجة صوتية تبين كيف الصوت العالي يغطي الهادي، وبعدين تتحول المجسمات لطائرة وبرج وجوال.
- **جوال بواجهة حيّة**: شاشة القفل، مركز التحكم، وزر وضع الطيران يتفعّل بالضبط مع كلمة "تفعّله" والإشارة تختفي.
- **تفاصيل حقيقية**: صوت "دت-دت-دت" اللي يطلع في سماعة الطيار من الجوالات (نبضات 217 هرتز)، جرس المقصورة "دينغ-دونغ"، شاشات القمرة تتشوش وقت كلمة "تتداخل".
- **لحظات درامية**: صوت نبض قلب ووقفة بعد كل سؤال ("وضع الطيران؟" — "صح؟" — "ما تشغّله؟")، ومشهد "إسقاط طائرة" يرجع للخلف (Rewind) مع "لا، لا…".
- 118 مؤثر صوتي، والصورة تسبق الصوت بـ 0.15 ث.

## اللقطات
| الكلام | المشهد |
|---|---|
| إذا ما فعّلت وضع الطيران | الطائرة بالليل فوق الغيوم + شريحة "AIRPLANE MODE · OFF" |
| جوالك ممكن يتسبب في | جوال على طاولة المقعد: "وضع الطيران: غير مفعّل" + موجات إشارة |
| إسقاط طائرة! | الطائرة تنزل بقوة + اهتزاز وتشويش |
| لا، لا… مو هذا اللي تتخيله! | المشهد يرجع للخلف (Rewind) والطائرة ترجع مستقرة |
| لكن… إشارات جوالك | ممر المقصورة والجوالات تبدأ ترسل |
| مستحيل تسبب مشاكل | "مستحيل" تنشطب بالأحمر + موجات تطلع من النوافذ |
| كيف جهاز صغير… أنظمة طائرة ضخمة؟ | جوال صغير على أرضية الحظيرة ← الكاميرا ترجع وتكشف الطائرة العملاقة |
| وليش يطلبون منك تفعيل وضع الطيران؟ | لوحة المقصورة تضيء + جرس ← مركز التحكم وزر الطيران ينبض + وقفة |
| خلّني أشرح لك | الكاميرا تغطس داخل الشاشة |
| تخيّل… شخص يتكلم معك بهدوء | هولوغرام: أنت + شخص بعيد، موجات هادية |
| شخص ثاني جنب أذنك | شخص ثالث جنب الأذن، موجات قوية، اللوحة تتشوش |
| صعوبة في سماع الأول، صح؟ | قريب من الأذن + وقفة |
| بدل الأصوات… إشارات لاسلكية | المجسمات تتحول: أنت ← طائرة، الشخص البعيد ← برج، القريب ← جوالك |
| الطائرة فيها أنظمة إلكترونية دقيقة | الطائرة تصير شفافة (أشعة X) وتبان الإلكترونيات والهوائيات |
| للتواصل والملاحة | من الأرض: برج يتواصل مع الطائرة + منارات ملاحة |
| ممكن الإشارات الصادرة من الأجهزة | كل جوالات الركاب تضيء + عدّاد |
| تتداخل… وتؤثر في عملها | موجات توصل للهوائيات ← قمرة القيادة: الشاشات تتشوش وسماعة الطيار تطلع "دت-دت" |
| هل… بمجرد ما تشغّله؟ | جوال يشتغل + وقفة |
| مو بالضرورة! مو كل جوال يسبب تداخل | أغلب الجوالات أخضر ✓، واحد بس يشوّش |
| احتياطات واختبارات وقواعد | الطائرة في الحظيرة + مسح فحص + ثلاث بطاقات ✓ |
| وهنا يجي دور وضع الطيران | الجوال + مركز التحكم ← الزر يتفعّل والإشارة تختفي |
| يتوقف عن إرسال واستقبال | من الأرض: خطوط الاتصال بين الطائرة والأبراج تنقطع |
| فالخلاصة… | "يطيح الطائرة" تنشطب ← "✓ الالتزام بالقواعد" ← "✓ تقليل احتمال التداخل" (فقاعة حماية حول الطائرة) |
| التزم بتعليمات طاقم الطائرة | إشارات المقصورة تومض ← جوالك على الطاولة: "وضع الطيران: مفعّل ✓" ← الطائرة تطير بعيد ← شعار KROZO |

## التحقق العلمي
كلامك دقيق ومتحفّظ، وما غيّرت ولا كلمة:
| المعلومة | الحالة |
|---|---|
| الجوال ما "يطيّح" الطائرة، لكن ممكن يسبب مشاكل في ظروف معينة | ✅ — هيئة الطيران الأمريكية FAA تمنع الأجهزة اللي ما ثبت إنها ما تتداخل مع أنظمة الطائرة (قاعدة من 1961، 14 CFR 91.21) |
| الطائرة فيها أنظمة تستقبل إشارات لاسلكية للتواصل والملاحة | ✅ |
| سلامة الطائرات تعتمد على احتياطات واختبارات وقواعد | ✅ — اختبارات تحمّل الطائرة للتداخل (معيار RTCA DO-307) وقواعد تشغيل الأجهزة (FAA AC 91.21-1C) |
| وضع الطيران يوقف الاتصال الخلوي | ✅ (في الجوالات الحديثة ممكن تشغّل الواي فاي والبلوتوث بعده) |
| ملاحظة إضافية | ⚠️ فيه سبب ثاني ما ذكرته: هيئة الاتصالات الأمريكية FCC تمنع الجوال الخلوي في الجو عشان ما يشوّش على **شبكات الجوال على الأرض** (الجوال في الجو يوصل لأبراج كثير مرة وحدة). مشهد "انقطاع الخطوط مع الأبراج" يلمّح لهذا بدون ما يغيّر كلامك |
| صوت "دت-دت" في السماعات | ✅ ظاهرة معروفة من جوالات GSM؛ استخدمته كمؤثر لكلمة "تؤثر في عملها" |
